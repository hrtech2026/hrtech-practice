# HRTech Practice 2026

Координационный репозиторий учебной практики. Здесь собрано всё, что нужно
команде до начала работы: регламент, расписание, критерии, методические указания
и витрина проектов.

Репозиторий доступен **только для чтения**. Правки вносятся преподавателем,
автоматикой или через Issue.

## С чего начать

| Шаг | Что сделать | Где |
|---|---|---|
| 1 | Пройти пошаговую инструкцию | [`docs/getting_started.md`](docs/getting_started.md) |
| 2 | Прочитать регламент и расписание | [`docs/reglament.md`](docs/reglament.md), [`docs/timeline.md`](docs/timeline.md) |
| 3 | Посмотреть критерии оценивания | [`docs/criteria.md`](docs/criteria.md) |
| 4 | Изучить методические указания | [`docs/methodology.md`](docs/methodology.md) |
| 5 | Создать заявку на команду | **New issue → Заявка на команду** |
| 6 | Дождаться репозитория | преподаватель проверит заявку и добавит метку `provision`, репозиторий создастся сам, ссылка придёт в комментарии к заявке |

Шаги 1–4 читаются до подачи заявки, шаг 5 — в любой момент до начала недели
работы.

Заявку можно править, пока репозиторий не создан: исправьте поля прямо в Issue
и напишите преподавателю, он добавит метку заново. Если состав поменялся уже
после создания репозитория, оформляется отдельная заявка **New issue →
Изменение состава** — права на запись выдаются только по заявке, вручную в
репозитории они не изменятся.

## Витрина проектов

Собранная витрина публикуется в этом же репозитории: если GitHub Pages
настроен, она доступна по адресу [https://<organization>.github.io/hrtech-practice/](https://hrtech2026.github.io/hrtech-practice/).

```text
data/teams.json   ← снимок реестра, обновляется автоматически
site/             ← собранная статика витрины
```

Снимок реестра формируется автоматикой из репозиториев команд и содержит
только публичные поля: состав, трек, этап, ссылки на артефакты и метрики
активности. Оценки экспертов видны после их публикации.

## Как устроена работа

```text
Заявка Issue  →  преподаватель  →  репозиторий команды  →  этапы  →  защита
                                  ↘  проверка при Pull Request
                                  ↘  агрегация цифрового следа
                                  ↘  доска статусов и витрина
```

Репозиторий команды создаёт преподаватель по заявке. Это сделано для того,
чтобы витрина и сбор статистики видели только настоящие команды: репозиторий
создаётся с меткой `hrtech-team`, по которой его находит агрегатор.

## Вопросы

Задавайте их через **New issue** с шаблоном «Вопрос по практике». Не создавайте
Issue в чужом командном репозитории — так вопрос потеряется среди задач команды.

Если не нашли ответ в FAQ, сначала посмотрите
[`docs/methodology.md`](docs/methodology.md): большинство вопросов возникает
из-за неполного заполнения разделов, а не из-за отсутствия указаний.
